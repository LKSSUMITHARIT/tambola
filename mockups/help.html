Help & User Guide

Everything you need to play or host a Tambola game.

🎟️ For players

  1. First login: register once with your Employee Code and email. One code ↔ one email.
  2. Join: enter the 6-character room code on Home, or pick a game under Live games.
  3. Tickets: in the lobby press “Get a ticket” (the host sets the limit). Tickets are final once the game starts.
  4. Play: watch the big Current Number. In Manual cutting rooms, tap a called number on your ticket to cut it; in Auto rooms numbers are cut for you.
  5. Claim: when you complete a winning case press its Claim button straight away. The server checks it against the numbers actually called.
  6. Wrong claims: you get a limited number of tries per prize (default 3); after that the prize is locked for you.
Claim fast! Each prize has a fixed number of winners — the first valid claims win.

🎙️ For hosts

  1. Create room: set name, limits, calling mode (Manual/Auto), cutting mode and the prize table.
  2. Share the room code. Watch players join in the console. You can lock the room or remove a player.
  3. Start once players hold tickets. Press Call next (Manual) or let the server call automatically (Auto).
  4. Claims appear live in the feed; prizes close automatically at their winner count.
  5. Delete a finished game to hide it from everyone; an Admin can restore it.

Hosts are appointed by an Admin. Hosts can't hold tickets in their own room.

🛡️ For admins

  • Hosts & Employees: search, Make Host / Revoke Host, activate/deactivate.
  • Reset password: gives a temporary password the employee must change at next sign-in.
  • Reports: leaderboard, totals, CSV export, audit log and Deleted games with Restore.
  • Sound: caller voice, volume and clips for every room.

❓ Troubleshooting

  • “Reconnecting…” banner: your connection dropped; the game resumes automatically.
  • Can't sign in: use Edge or Chrome on a domain-joined PC.
  • “Employee Code already registered”: ask the Admin to correct the record.
  • No sound: browsers only allow sound after you click something on the page.
